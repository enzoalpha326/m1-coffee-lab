# M1 Coffee Lab｜便携手动咖啡机概念项目

M1 Coffee Lab 是一个面向自驾、露营及有热水来源的短途旅行场景的便携手动咖啡机概念网站，用于课程研究、产品信息展示和 SEO 内容优化实践。

**本项目为课程研究用虚构概念。产品未制造、未实测，不销售、不接受预订。全部参数均为假设性设计设定。**

## 在线演示

- **初版网站**：https://m1-coffee-lab.vercel.app/
- **SEO 内容优化版 v1**：https://m1-coffee-lab-v1.vercel.app/

两个版本均保留产品的概念身份与使用边界。v1 明确了网页标题与 H1 的产品主题，分别编写三页摘要，并补充按压力气、按压次数、研磨粗细和水温的待验证问答；产品参数未改变。

## 产品设定与使用边界

- 工作方式为手动按压加压，设计上无需电池或电源。
- 热水和预磨咖啡粉需要另备；主机不加热、不保温。
- 仅使用咖啡粉，不兼容胶囊，不接受整颗咖啡豆，也不内置研磨器。
- 水仓、粉篮和杯体拟采用可拆卸设计；具体清洁方法与操作条件仍待验证，不宣称洗碗机适用。
- 没有热水来源、希望直接使用胶囊或需要多杯连续快速出品的场景，不适合这份概念设定。

| 概念参数 | 设计设定及口径 |
|---|---|
| 尺寸 | 高 175 mm，主体直径 70 mm |
| 主机重量 | 360 g，不含水、咖啡和携带袋 |
| 水仓容量 | 80 mL，不等于实际咖啡出液量 |
| 粉篮容量 | 8 g，不代表已验证的冲煮配方或推荐用量 |
| 拟用材料 | PP 外壳、不锈钢粉篮、硅胶密封件 |
| 概念配色 | 深灰、沙色 |
| 拟包含配件 | 主机、咖啡粉勺、收纳袋、概念说明卡 |

按压力气、按压次数、研磨粗细、水温、冲煮配方、压力、风味、出液量、出杯时间及密封表现均未取得实测验证；材料认证与耐温测试也尚未完成。网站不作专业级意式效果、稳定油脂或其他性能保证。

## 网站内容与技术

在线站点使用原生 HTML、CSS、JavaScript 和原创 SVG 概念插图，包含三个内容页：

1. **产品介绍**：产品定位、概念参数摘要、准备条件和适用场景。
2. **设计与使用说明**：部件设想、参数表、概念冲煮流程及常见问题；不是实物验证后的操作手册。
3. **项目说明**：课程定位、图像与参数来源，以及尚待验证的边界。

图片为原创概念示意图，不是产品实拍或测评。SEO 内容优化及外部链接不代表 Google 已收录或排名提升。
